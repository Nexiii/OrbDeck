# OrbDeck

**Your phone. Your deck. Your flow.**

OrbDeck turns a phone or tablet into a local-first command deck for OBS Studio, games, media, app links and Windows automation.

## Early Access

OrbDeck is currently available as a Windows 10/11 beta. Download the latest installer and updater files from the [Releases](https://github.com/Nexiii/OrbDeck/releases) page.

## Highlights

- Native OBS Studio controls for streaming, recording, scenes and audio sources
- Programs, files, URLs, Steam links, hotkeys, media keys and shell commands
- Custom pages, grids, icons and button states
- Browser-based phone interface with QR connection
- Local operation without a cloud account
- Optional password protection for the web interface
- English, German, French and Spanish interfaces
- Built-in signed updater

## Requirements

- Windows 10 or Windows 11
- A modern browser on the phone or tablet
- Both devices on the same private network
- OBS Studio 30.2 or newer for OBS integration

## Security

Only download OrbDeck from this repository or the official OrbDeck website. Release checksums are published alongside every installer.
